Go CLI · configuración

Falla rápido cuando .env se desvía.

Compara tu entorno real con la plantilla y detecta claves ausentes, vacías o extra antes de que el servicio arranque.

Ver repositorio ↗

Go 1.27 · sin dependencias · tests + CI

Qué comprueba

Tres errores, una salida clara

01

Claves ausentes

La plantilla pide una variable que el entorno no tiene. El proceso no debería arrancar.

02

Valores vacíos

La clave existe, pero el valor está vacío. Es el fallo que más tarde se convierte en un panic.

03

Claves extra

Un aviso por defecto. Con -strict se convierte en error para entornos controlados.

Instalación

Una línea

Go instala el binario en tu PATH. No hay dependencias que revisar.

go install github.com/melinoeluna4/envcheck@latest

Uso

En local o en CI

Archivos por defecto

envcheck

Lee .env y .env.example desde el directorio actual.

Modo estricto + JSON

envcheck -strict -json

Ideal para un pipeline que necesita un informe parseable y cero claves extra.
